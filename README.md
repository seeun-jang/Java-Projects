## 🎱 Mini Lotto Generator

Java 배열을 활용한 간단한 로또 번호 생성기입니다.

- 1~45 사이의 숫자 6개 생성
- 중복 번호 방지
- 오름차순 정렬

### Result

```text
Lotto Numbers
[5, 7, 25, 31, 38, 41]
```

## 🧪 Magic Potion Lab

Getter / Setter를 활용한 마법 포션 안정성 테스트 프로그램입니다.

- 포션의 온도, 마나, 독성 상태 관리
- Getter / Setter를 이용한 값 접근 및 변경
- 마법 에너지 주입 후 상태 변화
- 상태에 따라 안정성 판정

### Result

```text
+--------------------------------+
|         POTION STATUS          |
+--------------------------------+
| Name         : Moon Elixir     |
| Temperature  : 75              |
| Mana         : 80              |
| Toxicity     : 25              |
| Status       : STABLE          |
+--------------------------------+
```
